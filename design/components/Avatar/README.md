# Avatar

L'avatar est un disque `indigo-soft` avec les initiales du nom affiché en `indigo` ; Sugu n'a pas de photo de profil en V1.

## Usage

- 40 px (`sg-avatar`) dans les listes et la messagerie, 56 px (`sg-avatar--lg`) sur la page de l'annonce et le profil.
- Initiales : première lettre des deux premiers mots du `display_name`, en capitales (« Aminata Koné » → « AK »). Un seul mot : sa première lettre.
- La ligne vendeur `sg-seller` : avatar, nom en `body-strong`, « Membre depuis oct. 2026 · 3 annonces » en `small` `ink-muted`, puis l'action à droite (« Appeler » quand le téléphone est visible, sinon « Se connecter pour voir le numéro »).
- Le numéro de téléphone ne s'affiche qu'aux utilisateurs connectés ; avant, le bouton dit pourquoi.
